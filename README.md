# Fall Term AI Project

This repository contains an exploratory machine learning project developed during the fall term by Calvin Grabowski and James McGhee.

The project focuses on building and experimenting with ML models that analyze Spotify audio features to infer mood-related patterns in music. Custom-labeled data was combined with publicly available datasets to train and evaluate these models.

This work later evolved into a full web-based application with a production-ready backend. The main implementation and detailed documentation can be found here:
